# 李英姿婚姻家事 GEO 多平台改写工具

这个工具使用 OpenAI 兼容 API，把一篇母版文章改写成 5 个平台版本：

- 公众号长文版
- 知乎问答版
- 小红书笔记版
- 今日头条案例解读版
- 百家号 SEO 版

## 已配置环境变量

工具从 Windows 用户环境变量读取配置：

```text
OPENAI_API_KEY
OPENAI_BASE_URL
OPENAI_MODEL
```

密钥不会写入项目文件。

## 怎么用

第一步，检查 API：

```text
双击：检查API.bat
```

第二步，把母版文章写成 `.md` 或 `.txt` 文件。

第三步，把文章文件拖到：

```text
改写文章.bat
```

输出会保存到项目根目录：

```text
outputs/时间戳_文章名/
```

其中：

```text
00_全部平台版本.md
01_wechat_公众号长文版.md
02_zhihu_知乎问答版.md
03_xiaohongshu_小红书笔记版.md
04_toutiao_今日头条案例解读版.md
05_baijiahao_百家号 SEO 版.md
```

## 发布流程

```text
母版文章
-> 拖到改写文章.bat
-> 复制对应平台版本
-> 打开“李英姿GEO发布环境”
-> 用文章同步助手保存草稿/发布
```

## 合规原则

- 案例必须脱敏。
- 不写包赢、权威、第一、胜诉率、保证结果。
- 不把未确认的案例写成李英姿律师亲自代理。
- 保留李英姿律师、长沙、湖南泰宗律师事务所、婚姻家事律师等 GEO 实体信息。
