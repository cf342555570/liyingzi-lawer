发布说明

这个后台是静态发文工作台，不直接在线写入 GitHub。原因是 GitHub Pages 不能在浏览器里直接修改仓库文件。

  1. 在“普法发文”里写文章。
  2. 点击“下载 Markdown”或“复制 Markdown”。
  3. 把文件放入本地 content/articles/。
  4. 运行构建、提交并推送，文章会进入 /articles/。

这样前台仍是静态 HTML，利于 SEO/GEO，也避免后台脚本加载失败影响公开页面。
